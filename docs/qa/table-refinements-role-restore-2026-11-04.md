# Table refinements and role UI restoration — 04/11/2026

This change handles four explicit follow-ups. It does not revert the mixed IAM/users/audit redesign commit as a whole.

## Scope and evidence

- **OUT-01 filters:** the old 1150px container breakpoint forced search, middle filters and sort onto three rows with an expanded 300px sidebar. The filter breakpoint is now 900px, with proportional columns and two-line select labels inside 48px controls. Below 560px controls stack. Browser regression reproduced the old 120px vertical difference, then passed 11 cases: expanded/collapsed sidebar at 1920/1536/1440/1280, narrow layouts at 1024/768/390/320, dark mode and existing overview/filter alignment checks. No page overflow or clipped select text. Fixture/spec: `outbound-audit`.
- **WAR-01 primary codes:** measured actual `SKU-DEMO-003` text is Inter 15px/22px, weight 600. Existing documentation said 14px/700, while warranty nested `<strong>` escalated to weight 900. Warranty now matches actual SKU text; hover/focus have no underline and keyboard focus remains visible. Dark hover contrast was reproduced at 2.10:1 and corrected with the existing semantic link token. Four browser cases at 1440/390, light/dark compare real SKU and warranty screens and check computed typography, hover contrast and focus. The warranty unit file had 23 passes and one filter timeout under concurrent local load; that case passed separately in 7.6 seconds without changing the committed timeout.
- **INV-01 location:** removed the Vị trí column from current stock and redistributed widths to 100%, including actions. The real detail drawer already shows box, tray and normalized location; no duplicate fields or backend changes were needed. All 15 InventoryPage tests passed, including absence of location outside the drawer and presence of `BOX-01`, `TRAY-01`, `A-01-01` inside it.
- **IAM role presentation:** `4c71d1d` introduced the action-column matrix. The prior role cards, top paging and grouped permission tiles with visible permission keys are restored in the role tab only. Existing delegation, read-only, locked grants, dirty navigation, review reasons and version-conflict handling stay in place. Metadata, review and history continue using the current drawers. Group selection uses only editable permissions so a locked ungranted permission cannot prevent selecting and then clearing a group. All 18 role screen/helper tests passed. Four browser cases passed at 1440/768/390px and for save/conflict/history contracts; final card containment checks at 1440/390px passed after fixing long-code action clipping. The CI core command now includes these role tests.

Canonical decisions were updated in `docs/ui/DESIGN_FOUNDATIONS.md` and `docs/ui/sku-list-filter-table-style.md`. The primary-code typography supersedes the inaccurate old 14px/700 rule; body text and table headers keep their existing separate scales.
