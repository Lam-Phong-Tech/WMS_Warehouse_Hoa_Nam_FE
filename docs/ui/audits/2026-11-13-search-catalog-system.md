# Search audit: catalog, IAM, system and navigation — 2026-11-13

Scope: functional field promises, VI/EN/ZH copy, server/local filtering, pagination and authorization. Source review and focused automated checks; no live database writes or browser acceptance claim. Paths below are relative to the FE repo unless prefixed `BE:`. PV catalog/admin belongs to the operations audit.

## Findings and fixes

1. **Recipient keyword `0` returned unrelated records.** `BE:Modules/Warehouse/app/Http/Controllers/BaM1RecipientController.php:82` used PHP `empty()`, which treats the valid string `0` as absent. The predicate now checks the trimmed string against `''`; both `/recipients` and `/agencies` retain code/name/market/region search and filter before SQL pagination. `BE:tests/Feature/AgencyTest.php:34` covers all four promised fields, excludes an unrelated record, and checks page 2/total across both aliases.
2. **Model brand picker could not find brands after API page 1.** `src/modules/master-data/services/catalog-master.service.ts:212` fetched only 200 active brands. It now uses the existing guarded `readAllApiPages` loader, so local code/name filtering includes later pages. `catalog-master.service.test.ts` proves VI and ZH names from separate pages remain available.
3. **IAM role and department pickers were limited to API page 1.** `src/modules/iam/hooks/use-iam.ts:55` and `:72` now use complete-catalog service helpers with separate `all` cache keys. Local search includes every authorized role/department page; `useIamRolesPage` still requests one server page for the role table. `src/modules/iam/services/iam-search-catalogs.test.ts` checks page 2 and preserved ACTIVE filters for both helpers.
4. **Audit actor picker searched only its first 200 users.** The picker now uses a debounced server-mode autocomplete (20 matching users/request, keyword sent to `/users`). Its selected actor remains available when a later query excludes that actor. Existing translated IAM load-error and partial-user-result notices are reused. `AuditLogsPage.actor-search.test.tsx` covers server lookup, filtering logs by the returned user and preserving that selection outside new results.

No placeholder promise was weakened. No new shared translation keys were required. Existing SKU brand-name search was already implemented; it was not a defect.
